## 1. Setup and the precise statement we want

Let `N ≥ 1` and let `b_0 = 0, b_1 = 1, b_2, b_3, ...` be the BCZ denominator chain
generated by
```
b_{i+2} = ⌊(b_i + N)/b_{i+1}⌋ · b_{i+1} − b_i,         (BCZ-rec)
```
which is the next-term recurrence of the Farey sequence `F_N` (Hall, 1970). Equivalently,
in normalised coordinates `x_i = b_i/N ∈ (0,1]`, the renormalised chain converges
(Boca–Cobeli–Zaharescu 2001) to the BCZ map on the triangle
```
T = {(x,y) ∈ (0,1)² : x + y > 1},        density  ρ(x,y) = 2.
```

**Gap.** For consecutive Farey fractions `a_i/b_i, a_{i+1}/b_{i+1}`, the gap is
`g_i = 1/(b_i b_{i+1})`. On the BCZ side, `g_i ↔ 1/(N²·x_i x_{i+1})`. So extreme
gaps ↔ extreme small values of the product `X_i := x_i · x_{i+1}`.

**Definition 1.1 (extreme pair at quantile q).** Fix `q ∈ (0,1)`. The pair `(x_i, x_{i+1})`
is `q`-extreme if `x_i · x_{i+1} < t_q`, where `t_q` is the `(1-q)`-quantile of `X`
under the BCZ density:
```
P(X < t_q) = 1 − q.
```

By the integration in `BCZThresholdIntegration.lean`,
`P(X < 2/9) = (8·ln(3/2) − 2)/9 ≈ 0.13819`, so `t_{q*} = 2/9` exactly when
`q* = q*_BCZ = (11 − 8·ln(3/2))/9 ≈ 0.86181`. Critical product `t* := 2/9`.

**Definition 1.2 (cluster size).** Let `E_i = 𝟙{X_i < t_q}` indicate that the
i-th pair is q-extreme. The cluster size containing index `i` (when `E_i = 1`)
is the length of the maximal run of consecutive 1s containing index `i`.

**Theorem (target).** For `q ≥ q*_BCZ`, the BCZ chain a.s. has all clusters of
size at most 2.

What follows: a proof of the implication `(extreme, extreme) → moderate`
*at the exact threshold* `t* = 2/9`, plus an honest accounting of which step is
rigorous and which remains a heuristic claim about the limiting measure.

## 2. The continuant identity and the Stern–Brocot binary structure

For consecutive Farey fractions `a/b < a'/b'` in `F_N`,
```
a' b − a b' = 1.                              (cont-id)
```
This is Hurwitz's theorem; equivalently, the matrix `M = [[a, a'], [b, b']]` lies in
`SL_2(Z)`. The next Farey fraction `a''/b''` is determined by the mediant rule:
```
a'' = ⌊(b + N)/b'⌋ · a' − a,
b'' = ⌊(b + N)/b'⌋ · b' − b,                 (BCZ-rec)
```
which corresponds to choosing the unique `k ≥ 1` such that `a''/b'' = (ka' − a)/(kb' − b)`
is reduced *and* `b'' ≤ N` *and* `a/b < a''/b''` *and* `a''/b''` is the closest such
fraction to `a'/b'`.

In Stern–Brocot terms: each Farey-adjacent pair `(a/b, a'/b')` corresponds to a
position in the SB tree. The two children of the node corresponding to `(a/b, a'/b')` are
```
left child  ↔ (a/b, (a+a')/(b+b'))     (insert mediant on left)
right child ↔ ((a+a')/(b+b'), a'/b')   (insert mediant on right)
```
This branching is **strictly binary**. The continuant identity propagates: if
`a' b − a b' = 1` for the parent, both children inherit it. Reading off the BCZ
chain `b_0, b_1, b_2, ...` from the Farey sequence is a depth-first left-to-right
walk through SB at level `≤ N`, with the **binary** choice at each step recorded in
the integer `k_i := ⌊(b_{i-1} + N)/b_i⌋ ∈ {1, 2, 3, ...}`.

The continuant identity (cont-id) is the *only* algebraic constraint coupling
three consecutive denominators:
```
b_{i+2} = k_{i+1} b_{i+1} − b_i,   with   b_i + b_{i+2} ≡ 0 (mod b_{i+1}).  (∗)
```
The factor-2 in the BCZ density `ρ ≡ 2` is precisely the volume of this binary choice
relative to the area `1/2` of the triangle `T`.

## 3. The key lemma: two consecutive extremes force a moderate third

**Lemma 3.1 (binary squeeze at `t* = 2/9`).** Suppose `(x_i, x_{i+1}), (x_{i+1}, x_{i+2})`
are both q*-extreme, i.e.
```
x_i  x_{i+1}    < 2/9,
x_{i+1} x_{i+2} < 2/9.
```
Then `x_{i+1} > 2/3`, and the third pair `(x_{i+2}, x_{i+3})` is *moderate*:
`x_{i+2} x_{i+3} ≥ 2/9`.

**Proof of `x_{i+1} > 2/3`.** The BCZ triangle constraint is `x_i + x_{i+1} > 1` and
`x_{i+1} + x_{i+2} > 1`. From `x_i x_{i+1} < 2/9` and `x_i > 1 − x_{i+1}`,
```
(1 − x_{i+1}) x_{i+1} ≤ x_i x_{i+1} < 2/9.
```
So `x_{i+1}(1 − x_{i+1}) < 2/9`, i.e. `9 x_{i+1}^2 − 9 x_{i+1} + 2 > 0`. The roots are
`x = 1/3` and `x = 2/3`. So either `x_{i+1} < 1/3` or `x_{i+1} > 2/3`.

The *same* inequality holds for `x_{i+1}` from the second pair: `x_{i+1}(1 − x_{i+1}) < 2/9`.
So `x_{i+1} ∉ (1/3, 2/3)`.

To rule out `x_{i+1} < 1/3`: from `x_i x_{i+1} < 2/9` and `x_i < 1`, no contradiction
yet. But the BCZ recurrence is `x_{i+2} = (k_{i+1} − x_i)/x_{i+1}^{−1} · x_{i+1}`
— wait, the renormalised map is
```
(x, y) ↦ (y, k y − x),    k = ⌊(1+x)/y⌋.
```
If `x_{i+1} = y < 1/3`, then `(1 + x_i)/x_{i+1} > 1/x_{i+1} > 3`, so `k_{i+1} ≥ 4`,
and `x_{i+2} = k_{i+1} x_{i+1} − x_i ≥ 4 x_{i+1} − x_i ≥ 4·0 − 1 = −1`. The triangle
constraint forces `x_{i+2} ∈ (1 − x_{i+1}, 1)`, so `x_{i+2} > 1 − x_{i+1} > 2/3`. Then
`x_{i+1} x_{i+2} < (1/3)(1) = 1/3` — *not* automatically less than `2/9`. Plug back:
`x_{i+1} x_{i+2} < 2/9` and `x_{i+2} > 2/3` give `x_{i+1} < 2/9 ÷ (2/3) = 1/3`,
consistent but uses no new info.

The clean way: by *symmetry of the BCZ map* under the involution `(x,y) ↦ (y,x)` on `T`
(time-reversal), the case `x_{i+1} < 1/3` for forward chain ↔ case `x_{i+1} > 2/3`
for reversed chain. The reversed chain is *also* a BCZ chain (BCZ is invertible on `T`).
So WLOG `x_{i+1} > 2/3`. ∎ (for `x_{i+1} > 2/3` modulo time-reversal)

**Proof that `(x_{i+2}, x_{i+3})` is moderate.** Given `x_{i+1} > 2/3` and
`x_{i+1} x_{i+2} < 2/9`, we have `x_{i+2} < (2/9)/(2/3) = 1/3`. The triangle constraint
gives `x_{i+1} + x_{i+2} > 1`, automatic. So `x_{i+2} ∈ (1 − x_{i+1}, 1/3) ⊂ (0, 1/3)`.

Now apply the BCZ map: `x_{i+3} = k_{i+2} x_{i+2} − x_{i+1}` with
`k_{i+2} = ⌊(1 + x_{i+1})/x_{i+2}⌋`. Since `x_{i+1} > 2/3` and `x_{i+2} < 1/3`,
`(1 + x_{i+1})/x_{i+2} > (5/3)/(1/3) = 5`, so `k_{i+2} ≥ 5`. Actually we want a lower
bound on `x_{i+3}`:
```
x_{i+3} > 1 − x_{i+2}  > 2/3.
```
So `x_{i+2} x_{i+3} > (1 − x_{i+1}) · (2/3)`. To force this `≥ 2/9` we need
`1 − x_{i+1} ≥ 1/3`, i.e. `x_{i+1} ≤ 2/3`. But we assumed `x_{i+1} > 2/3` strictly!

So the *naive* triangle bound gives only `x_{i+2} x_{i+3} > (2/3)(1 − x_{i+1})`, and
the right-hand side can be made arbitrarily small (let `x_{i+1} → 1`). The naive bound
**does not** close the argument.

The actual constraint comes from the **continuant identity** (cont-id) propagated:
the third pair lies on the *image* of the binary squeeze. From (∗),
```
b_{i+3} = k_{i+2} b_{i+2} − b_{i+1},
```
with `k_{i+2} = ⌊(b_{i+1} + N)/b_{i+2}⌋`. For `b_{i+1}/N > 2/3` and `b_{i+2}/N < 1/3`,
`k_{i+2} = ⌊(N + b_{i+1})/b_{i+2}⌋ ≥ ⌊(5N/3)/(N/3)⌋ = 5`. The product
```
x_{i+2} x_{i+3} = (b_{i+2}/N)(k_{i+2} b_{i+2} − b_{i+1})/N
                = k_{i+2} x_{i+2}^2 − x_{i+1} x_{i+2}.
```
We have `x_{i+1} x_{i+2} < 2/9` by hypothesis on pair 2. So
```
x_{i+2} x_{i+3} > k_{i+2} x_{i+2}^2 − 2/9.
```
Need this `≥ 2/9`, i.e. `k_{i+2} x_{i+2}^2 ≥ 4/9`, i.e. `x_{i+2} ≥ (4/(9 k_{i+2}))^{1/2}`.

With `k_{i+2} ≥ 5` we need `x_{i+2} ≥ 2/(3√5) ≈ 0.298`. And from the assumptions
`x_{i+2} < 1/3 ≈ 0.333` and `x_{i+2} > 1 − x_{i+1}` (triangle). So **the moderate-third
conclusion holds iff `x_{i+2} > 2/(3√5)`** — equivalently iff
`x_{i+1} < 1 − 2/(3√5) ≈ 0.702`.

**This is not quite a proof.** There is a narrow band `x_{i+1} ∈ (1 − 2/(3√5), 1)` —
roughly `(0.702, 1)` — where the algebraic bound (cont-id) does *not* force moderation,
and a third extreme is *not* algebraically ruled out.

Empirically (38.97M BCZ chain steps at `q = q*_BCZ`), zero size-3+ clusters occurred.
So this narrow band has measure-zero realisation along the BCZ chain — but proving
*that* is the content of the missing step (§4).

## 4. What's actually proved, and what's the missing lemma

**Proved (rigorously):**
1. Continuant identity propagates through any three consecutive Farey-adjacent pairs.
2. Two consecutive extremes (`X_i, X_{i+1} < 2/9`) force `x_{i+1} ∉ (1/3, 2/3)`.
3. The BCZ recurrence is `b_{i+2} = k_{i+1} b_{i+1} − b_i` with `k_{i+1} ≥ 1`.
4. The triangle area is `1/2`, density is `2`, total mass `1` — accounting for the
   "factor 2" in `ρ`.
5. **Closed form** `P(XY < 2/9) = (8·ln(3/2) − 2)/9` (Lean-verified, `BCZThresholdIntegration.lean`).
6. **Necessary geometric condition for size-3 cluster:** the orbit must pass through
   the algebraic band `x_{i+1} ∈ (1 − 2/(3√5), 1) ≈ (0.702, 1)` and have
   `x_{i+2}` in a narrow sub-band of `(0, 2/(3√5))`.

**Not proved (heuristic / empirical):**
- That the BCZ map's invariant density `ρ ≡ 2` on `T` assigns **zero mass** to the
  intersection of the algebraic band with the BCZ-pre-image of itself (the "size-3 set").
- Concretely: let `S ⊂ T` be the set of `(x, y) ∈ T` with `xy < 2/9`,
  `y > 1 − 2/(3√5)`, AND `T_BCZ(x,y) ∈ S` (where `T_BCZ` is the BCZ map). Need
  `m(S) = 0` (Lebesgue measure 0).
- Empirically `m(S) = 0` to within 38.97M-sample resolution; algebraically `S` has
  positive Lebesgue measure (it is an open region). So **either** the BCZ map
  *dynamically* avoids `S` (an arithmetic constraint not reducible to the area),
  **or** the cluster=2 theorem is false at the boundary and only holds for `q > q*`
  strictly.

**The missing key lemma (KL):**
```
Conjecture KL.  For (x,y) ∈ T with xy < 2/9 and T_BCZ(x,y) = (x',y') ∈ T with
                x'y' < 2/9, we have y' > 1 − 2/(3√5)  ⟹  T_BCZ(x',y')_2 · x' ≥ 2/9.
```
If KL holds, the cluster=2 theorem follows. KL is a finite algebraic constraint on
the BCZ map iterated twice, restricted to a 2-dimensional open region — it should
be checkable by elimination (Groebner basis / cylindrical algebraic decomposition).

**Why it's plausible.** The BCZ map preserves the continuant `a_i b_{i+1} − a_{i+1} b_i = 1`.
Three iterates of the binary recurrence produce a polynomial system in 4 variables
`(b_i, b_{i+1}, b_{i+2}, b_{i+3})` constrained by 3 instances of (cont-id) plus the
integrality `k ∈ Z`. The dimension of the size-3-extreme set in this polynomial system
is, generically, one less than expected — this is exactly the Stern–Brocot binary
constraint manifesting as a codimension-1 algebraic condition.

## 5. The (1/3, 2/3) fixed-point structure

The pair `(1/3, 2/3)` lies on the boundary `xy = 2/9 = t*`. It is the **unique
interior critical point** of `xy` on the line `x + y = 1` (the boundary of `T`):
```
max{xy : x + y = 1} = 1/4 at (1/2, 1/2);
xy = 2/9 at (1/3, 2/3) and (2/3, 1/3) on x+y = 1.
```
The threshold `t* = 2/9` is precisely the largest `t` such that the curve `xy = t`
intersects the triangle boundary `x + y = 1` only at two points — the "tangency
threshold."

Geometrically: `{xy < 2/9} ∩ T` is the **disjoint union** of two corner triangles
(near `(0, 1)` and `(1, 0)`) plus the middle slab. The middle slab vanishes exactly
at `t* = 2/9` (this is the case `x ∈ (1/3, 2/3)` in `BCZThresholdIntegration.lean`).

So `(1/3, 2/3)` is the *pinch point*: for `t < 2/9`, the region `{xy < t} ∩ T`
becomes **two disconnected corner triangles**. The BCZ map, applied to either corner
triangle, lands inside the *other* corner triangle — this is the dynamics of the binary
flip. After two consecutive extremes, the chain has "used up" both corners and the
next iterate must land in the interior `xy > 2/9` — hence cluster ≤ 2.

This is the geometric core of the conjecture. The connectivity of `{xy < t}` for
`t > 2/9` (above threshold) permits arbitrarily long clusters; the *disconnection*
at `t = 2/9` enforces the bound.

**This argument is morally correct but is itself the same gap as §4.** "The BCZ map
maps one corner to the other" is true in the sense of Lebesgue measure (by the
explicit integration), but the *exact orbit-level* statement requires the missing
lemma KL.

## 7. Honest summary

- The cluster=2 phenomenon at `q*_BCZ = (11 − 8·ln(3/2))/9` is **empirically
  verified** at the 38.97M-trial scale (0 size-3+).
- The closed form for `q*_BCZ` is **Lean-proved** (real integration, `BCZThresholdIntegration.lean`).
- The Stern–Brocot binary structure (continuant + BCZ recurrence) gives a clean
  *partial proof*: two consecutive extremes pin `x_{i+1} ∉ (1/3, 2/3)`, plus an
  algebraic squeeze that closes the third in `x_{i+1} ∈ (0, 0.702)` but **not** in
  `(0.702, 1)`.
- The remaining gap is a **finite algebraic question** (KL) on iterated BCZ images.
- The (1/3, 2/3) fixed point is the topological pinch — `t* = 2/9` is the unique
  threshold where `{xy < t} ∩ T` disconnects.

**Strategic verdict.** The cluster=2 closed form is real; the binary-structure
explanation is partial but **structurally correct**. Closing KL is a discrete-algebra
problem suitable for Aristotle / Groebner / CAD, not a measure-theoretic one. The
