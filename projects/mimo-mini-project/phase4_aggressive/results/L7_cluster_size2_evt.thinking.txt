The BCZ recurrence k_{i+2} = κ k_{i+1} - k_i creates a 2-step dependence. If we define y_i = (k_i, k_{i+1}), then {y_i} is a Markov chain (in fact, it's deterministic given y_0, so it's a degenerate Markov chain). The gap d_i = 1/(k_i * k_{i+1}) is a function of y_i.

For the extreme behavior: when d_i is very large, this means k_i * k_{i+1} is very small. Since k_i and k_{i+1} are positive integers, this means at least one of them is 1, and the other is small. In this case:
- d_{i+1} = 1/(k_{i+1} * k_{i+2}) = 1/(k_{i+1} * (κ k_{i+1} - k_i))
- If k_{i+1} = 1: d_{i+1} = 1/(κ - k_i). This is large if k_i is small.
- If k_{i+1} = 2: d_{i+1} = 1/(2*(2κ - k_i)). This is also large if κ is small.

Then:
- d_{i+2} = 1/(k_{i+2} * k_{i+3}) = 1/((κ k_{i+1} - k_i) * (κ(κ k_{i+1} - k_i) - k_{i+1}))
- This involves products of larger numbers, so d_{i+2} is typically small (normal).

This explains the cluster size 2: the recurrence ensures that after two consecutive large gaps, the next gap involves larger denominators and is thus normal.

The key insight is that the BCZ recurrence "amplifies" the small denominators over two steps but then the denominators grow back to normal. This creates exactly 2 consecutive large gaps.
