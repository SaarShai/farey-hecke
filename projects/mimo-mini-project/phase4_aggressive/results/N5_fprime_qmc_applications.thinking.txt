## Analysis of F'_N properties

First let me understand the key structural properties:

1. **Denominator structure**: Every point has a prime denominator. The denominators are "roughly uniform" in the sense that there are many primes near N, and each prime $q$ contributes $q$ points. So large denominators dominate.

2. **Fourier-analytic perspective**: For a rational $p/q$ with $q$ prime, the exponential sums involve $e^{2\pi i k p/q}$ summed over $p$. By orthogonality, $\sum_{p=0}^{q-1} e^{2\pi i k p/q} = q$ if $q | k$ and 0 otherwise. This is crucial.

3. **Star discrepancy**: $D^*(F'_N) \sim C/N \sim C'/\sqrt{M}$, which is worse than optimal 1D sequences ($\sim \log M / M$) but better than random.

4. **Lag-1 gap correlation**: Collapses to ~0. This means consecutive gaps are nearly independent — no clustering. This is fundamentally different from Farey sequences $F_N$ which have strong gap correlations.

5. **Gap distribution**: Heavy-tailed but not boundary-dominated. This is because small gaps occur only between fractions with large prime denominators (close primes can have fractions close together), while large gaps occur near boundaries.
