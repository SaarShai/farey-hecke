## Concrete Computational Experiment: Testing the Farey Persistence Claim

### Objective
To verify whether the persistence diagram of Farey fractions on the circle exhibits a second persistent 1-cycle with a birth-death ratio approximately 3, as claimed.

### Hypothesis
- **Null Hypothesis (H0):** There is no second persistent cycle with death/birth ≈ 3.
- **Alternative (H1):** The second longest-lived H₁ feature has death/birth ≈ 3.

### Experimental Design

#### 1. Data Generation
- Generate Farey fractions of order N (denominators ≤ N).
- Map each fraction \(p/q\) to a point on the unit circle: \(e^{2\pi i p/q}\).
- Exclude \(p/q = 1\) (same as \(0\)) to avoid duplicates.
- Use N = 100 (≈3039 points), tractable for persistent homology computations.

#### 2. Distance Metric
- Use Euclidean distance in \(\mathbb{R}^2\) (chord distance), which is monotonic with geodesic distance on \([0, \pi]\).

#### 3. Filtration
- Build Vietoris-Rips complex with parameter \(\varepsilon\) (edge added if distance ≤ \(\varepsilon\)).
- Compute persistent homology in dimension 1 (H₁) using **ripser** (efficient for Vietoris-Rips).

#### 4. Persistence Analysis
- Extract (birth, death) pairs for H₁ features.
- Sort by lifetime (death − birth).
- The longest-lived feature is the fundamental cycle of the circle.
- The **second longest-lived feature** is tested for death/birth ≈ 3.

#### 5. Quantitative Prediction
If the claim is true, the second cycle should satisfy:
\[
\frac{\text{death}}{\text{birth}} \approx 3 \quad (\text{with tolerance } \pm 0.5).
\]
Otherwise, the claim is refuted, and we record the actual ratio.

### Python Recipe
```python
import numpy as np
from scipy.spatial.distance import pdist, squareform
from ripser import ripser
from persim import plot_diagrams
import matplotlib.pyplot as plt
from math import gcd

def farey_points(N):
    """
    Generate Farey fractions of order N as points on the unit circle.
    Returns array of (x, y) coordinates.
    """
    points = []
    for q in range(1, N+1):
        for p in range(q):
            if gcd(p, q) == 1:
                angle = 2 * np.pi * p / q
                points.append((np.cos(angle), np.sin(angle)))
    return np.array(points)

def main(N=100):
    print(f"Farey points for N={N}...")
    pts = farey_points(N)
    print(f"Number of points: {len(pts)}")

    # Pairwise Euclidean distances
    dists = pdist(pts, metric='euclidean')
    dist_matrix = squareform(dists)

    # Persistent homology (H1 only)
    print("Computing persistent homology (this may take a few minutes)...")
    diagrams = ripser(dist_matrix, maxdim=1, distance_matrix=True)

    # Extract H1 persistence
    pers_1 = diagrams['dgms'][1]
    lifetimes = pers_1[:, 1] - pers_1[:, 0]

    # Sort by lifetime descending
    idx = np.argsort(lifetimes)[::-1]
    pers_sorted = pers_1[idx]
    lifetimes_sorted = lifetimes[idx]

    # Print top features
    print("\nTop 5 persistent H1 features:")
    for i in range(min(5, len(pers_sorted))):
        b, d = pers_sorted[i]
        life = lifetimes_sorted[i]
        ratio = d / b if b > 0 else float('inf')
        print(f"  {i+1}: birth={b:.6f}, death={d:.6f}, lifetime={life:.6f}, ratio={ratio:.6f}")

    # Test second feature
    if len(pers_sorted) >= 2:
        b2, d2 = pers_sorted[1]
        ratio2 = d2 / b2 if b2 > 0 else float('inf')
        print(f"\nSecond persistent cycle: birth={b2:.6f}, death={d2:.6f}, ratio={ratio2:.6f}")
        if abs(ratio2 - 3) < 0.5:
            print("=> SUPPORTS claim: ratio ≈ 3")
        else:
            print(f"=> REFUTES claim: ratio = {ratio2:.4f} ≠ 3")
    else:
        print("\nNo second persistent cycle found.")

    # Plot persistence diagram
    plt.figure(figsize=(8, 8))
    plot_diagrams(diagrams['dgms'], show=False)
    plt.title(f"Persistence Diagram (H1) for Farey N={N}")
    plt.savefig(f"farey_persistence_N{N}.png")
    print(f"\nSaved plot to farey_persistence_N{N}.png")

if __name__ == "__main__":
    main(N=100)  # Increase N if time permits, but 100 is sufficient
```

- Test smaller N (e.g., 50, 80) to check stability.
- Verify that the fundamental cycle is indeed the longest-lived feature.
- Consider alternative metrics (e.g., geodesic distance) if results are ambiguous.
