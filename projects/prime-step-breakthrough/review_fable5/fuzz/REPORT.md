## Claim verdicts

### 1. `quota_order` — quota-validity + strict factor &lt; 3 vs unconstrained OPT_B

**HOLDS (1000 instances).**

- Enumerated all count vectors with `sum(counts) ≤ 9` and `1..4` categories (incl. zeros): **1000**.
- Quota-window violations: **0**.
- Solver errors: **0**.
- Certificate `max_discrepancy` matched independent after-prefix metric: **all**.
- Ratio `B(quota_order) / OPT_B` (positive categories ≥ 2): **max = 2** at counts `(2, 1)`  
  - order `[0,0,1]`, `B=2/3`, OPT order `[0,1,0]`, `OPT_B=1/3`.
- No ratio ≥ 3 observed.

### 2. `quota_mechanical_order` — prefixwise exact optimality of B and Q (binary)

**HOLDS (91 pairs).**

- All `(a,b)` with `a+b ≤ 12`: **91**.
- Mechanical B,Q matched exhaustive unconstrained lex optimum on every pair.
- Matched independent `nearest_binary_mechanical`.
- **Lower word not minimax for (1,4): confirmed**  
  - lower `[1,1,1,1,0]` → `B=4/5`, `Q=2`  
  - OPT/nearest `[1,1,0,1,1]` → `B=2/5`, `Q=6/5`.

### 3. `solve_constrained_quota` — `L ≤ OPT_B ≤ U`, constraints, U = recomputed B

**HOLDS (500 solver-accepted feasible instances)** for the certificate claim on the **accepted** comparison set.

| Metric | Count |
|--------|------:|
| Solver-accepted feasible, certificate OK | 500 |
| Solver/oracle agree infeasible | 1830 |
| Interval / constraint / U-mismatch failures | 0 |
| Other unexplained infeas disagreements | 0 |
| `PIN_SPLITS_BLOCK` vs expanded-oracle feasible | 89 |

**Documented restriction (not a silent math bug, but a sharp edge):**  
pins that only partially cover a fixed block are rejected with `PIN_SPLITS_BLOCK`, while the expanded-order oracle still counts those instances as feasible. Contract text (`FABLE5_ADVERSARIAL_REVIEW_PACKET.md` §5, `OPERATIONAL_ARCHITECTURE.md`) lists “arbitrary interior pins that split a block” as unsupported.

Reproducer: `review_fable5/fuzz/repro_findings.py` → `pin_splits_block()`  
Instance: counts `{a:0,b:3}`, block `(b1,b2,b3)`, suffix pin `(b3)` → oracle feasible (1 order), solver raises `PIN_SPLITS_BLOCK`.

Systematic edges exercised: repeated-category blocks, block+pin, precedence chains, zero-count categories, single-category, equal counts, divisible/non-divisible N.

### 4. `solve_exact` — lex (B, Q) vs brute force

**HOLDS (547 unique instances).**

Families (deduped by contribution/mass multiset):

- 1-D signs `{±1}`, `N≤7`
- 1-D alphabet `{-2..2}`, `N≤4`
- 1-D fractions `{±1/2,±1/3,2/3}`, `N≤4`
- 2-D `{-1,0,1}^2`, `N≤3`
- masses in `{1,2}` with signs, `N≤4`

Also verified known traps: `SEVEN_ITEM_LEX_COUNTEREXAMPLE` and `SUM_FIRST_COUNTEREXAMPLE` — `solve_exact` matches exhaustive; flawed single-label DP does not.

No solver errors on these inputs.

### 5. Determinism (dict insertion / UTF-8 names)

**HOLDS (11 instances).**

- Same latin name→count mapping under different insertion orders → identical `categories`, `order_codes`, digest, B.
- UTF-8 names (`cafe` / `café` / `caffè`) → identical outputs across insertion orders (UTF-8 byte sort).
- `solve_constrained_quota` with remapped dict order → identical packed codes/digest.

Not label-order-dependent once keys are normalized.
