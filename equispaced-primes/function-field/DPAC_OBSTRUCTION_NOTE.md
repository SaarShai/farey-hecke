## 1. Object and statement

`c_K(s) = Σ_{k=2}^{K} μ(k) k^{-s}`  (truncated Möbius–Dirichlet polynomial).

**DPAC(K):** for fixed `K ≥ 2`, `c_K(ρ) ≠ 0` for every nontrivial zero `ρ`
of `riemannZeta` (`riemannZeta ρ = 0`, `0 < Re ρ < 1`).

Fixed-`β` form. Write `ρ = β + iγ`. Then
`c_K(ρ) = Σ_{k=2}^{K} μ(k) k^{-β} e^{-iγ ln k}` `=: f_{K,β}(γ)`,
a finite real-variable exponential sum with frequencies `{ln k : 2 ≤ k ≤ K,
μ(k) ≠ 0}` (the squarefree `k`). `c_K` has infinitely many critical-strip
zeros (Langer 1931 [CITATION-UNVERIFIED]); DPAC's content is only that none
of them sits on a ζ-zero.

## 2. Unconditional ceiling — exactly K ≤ 4 [PROVEN, elementary]

Reverse-triangle / norm-domination lower bound:
`|c_K(ρ)| ≥ 2^{-β} − Σ_{k=3}^{K} |μ(k)| k^{-β}`.

- **K=2:** `c_2 = −2^{-ρ}`, `|c_2| = 2^{-β} > 0`. Single term. ✓
- **K=3, K=4:** effective terms `k=2,3` only (`μ(4)=0`).
  `c_3 = c_4 = −(2^{-ρ}+3^{-ρ})`. `c=0 ⇒ 2^{-β}=3^{-β} ⇒ β=0`,
  excluded since `β ∈ (0,1)`. ✓ unconditional.
- **K=5 — first open case [PROVEN the bound fails for all β∈(0,1)]:**
  `c_5 = −(2^{-ρ}+3^{-ρ}+5^{-ρ})`. Domination needs
  `g(β) := 2^{-β} − 3^{-β} − 5^{-β} > 0`. But `g(0)=−1`, `g(1)=−1/30`,
  and `g` is < 0 on all of `[0,1]` (e.g. `g(½)=0.7071−0.5774−0.4472
  = −0.3175`). So no unconditional norm bound exists from `K=5` on; the
  Diophantine (phase) content is genuinely present for **every K ≥ 5**.

This pins the boundary precisely: DPAC is elementary iff `K ≤ 4`; the hard
content begins at exactly `K = 5`, not asymptotically.

## 3. The reduction chain (encoded in `DPAC_closure_attempt.lean`)

Mathematically elementary, hand-checked here. (Lean-encoding status: §6.)

Let `Z_{K,β} := { γ ∈ ℝ : f_{K,β}(γ) = 0 }` be the real zero set of the
fixed-`β` exponential sum.

- **PREREQ-1 (Pólya–Langer discreteness/count).** For `K ≥ 2`, `f_{K,β}`
  is a *nontrivial* finite exponential sum (the `k=2` coefficient is
  `μ(2)·2^{-β} = −2^{-β} ≠ 0`). Its real zeros are isolated; `Z_{K,β}` is
  discrete (no finite accumulation) and its counting function on `[0,T]` is
  `O_K(T)` — linear in `T`, *bounded* by `(ln K / 2π)·T + O(1)` type density.
  Classical (Pólya 1913; Langer 1931; Moreno 1973) [CITATION-UNVERIFIED —
  primary PDFs not pulled this session]. Not in Mathlib v4.28.0.
- **Bridge identity [PROVEN, elementary].** Converting `(k:ℂ)^{-ρ}` to
  `k^{-β} e^{-iγ ln k}` is exact for `k > 0`. Hence, for `K ≥ 2`,
  `c_K(ρ) ≠ 0  ⟺  γ ∉ Z_{K,β}` (`= FiniteLogRatioLI(K,β,γ)` in the file).
  Lean: `dpac_iff_ordinate_avoidance`, `dpac_of_FLRLI`.
- **PREREQ-2 (the genuine content).** No nontrivial ζ-zero ordinate `γ`
  with `Re = β` lies in `Z_{K,β}`, for all `K ≥ 2`, all such `β`.

**Conclusion.**  `PREREQ-1 + PREREQ-2 ⟹ DPAC`, and `DPAC ⟹ PREREQ-2`.
So, modulo the *classical* PREREQ-1,
> **DPAC ≡ PREREQ-2:** *no nontrivial zeta-zero ordinate is a root of the
> associated finite Möbius exponential polynomial.*
A single, clean, named obstruction.

## 4. Why PREREQ-2 is LI-class — and is NOT the LI hypothesis [analysis]

`LI` (Linear Independence hypothesis): the positive ζ-ordinates `{γ_n}` are
ℚ-linearly independent.

**DPAC neither follows from nor implies LI** (correctly tombstoned in
`DPAC_full.lean`, `DPAC_LI_BRIDGE_DEPRECATED`). Precise reason:

- `Z_{K,β}` is governed by the **additive structure generated by
  `{ln k : k ≤ K squarefree}`** (equivalently `{ln p : p ≤ K}`).
  Membership `γ ∈ Z_{K,β}` is a *single transcendental equation in the one
  number `γ`*, with coefficients depending on `β` and the prime logarithms.
- `LI` constrains **ℚ-linear relations among the `γ_n` with each other** —
  a different structure. Independence of the `γ_n` says nothing about whether
  one `γ_n` solves the prime-log equation `f_{K,β}(γ_n)=0`; conversely
  avoiding those equations gives no ℚ-relations among ordinates.

So PREREQ-2 is a **non-resonance statement between the ζ-spectrum and the
prime-log lattice** — the *same Diophantine-hardness family* as LI, simple
zeros, and pair-correlation independence, but logically independent of LI.
"LI-class" = comparable depth / known-unreachable family, **not** "reducible
to LI". No unconditional method is known; **GRH does not deliver it**
(GRH places the `γ_n`; it says nothing about their arithmetic relation to
`{ln p}`).

## 5. What *is* reachable (and exactly what it does NOT give)

- **Density-one avoidance — skeleton only.** Langer `O_K(T)` vs
  Riemann–von Mangoldt `N(T) ~ (T/2π) ln T` gives, *if* the two external
  counts and an intersection bound are supplied,
  `#{n ≤ N : c_K(ρ_n)=0}/N → 0`. Lean `density_zero_from_growth_comparison`
  formalizes **only the real-analysis skeleton** (`O(T)/Θ(T ln T) → 0`).
  It does **not** prove density-one (needs the two counting inputs +
  intersection bound, none in Mathlib) and says **nothing** about the
  pointwise every-zero claim. Honest status: skeleton, not a theorem about ζ.
- **Certified finite verification** (this handoff, §see results). Rigorous
  for a *finite* height range only; no asymptotic content; cannot approach
  the general-K conjecture.
- **GRH-conditional heuristics** ("Mertens spectroscope"): background
  plausibility, not proof, not even of density-one.
