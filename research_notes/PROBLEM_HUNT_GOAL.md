# GOAL — find a problem we CAN genuinely contribute to (stop guessing the owned thing)

Date 2026-06-20. Repeated failure mode: we keep proposing the FAMOUS version of a problem in a
WELL-CULTIVATED area (non-arith Hecke / QUE / Phillips-Sarnak / arithmeticity) -> every idea turns
out OWNED (Sarnak, Pohl, Bruggeman, Takeuchi, ...). FIX: do NOT guess; SURVEY widely, filtered hard
by our ACTUAL edge, and find an open problem where a concrete VERIFIABLE contribution is realistic.

## OUR REAL EDGE (match problems to THIS, not to prestige)
- Fleet of parallel REASONING agents + adversarial falsification (kill spurious fast).
- Exact / interval-certified computation (Arb, exact arithmetic), structured search.
- Formal verification (Lean/Aristotle) to make a claim bulletproof.
- A number-theory/dynamics collaborator (Koyama).
- NOT: a supercomputer (Kaggle is modest) -> avoid raw-FLOPS-bound problems.
- NOT: the deep-analytic frontier (minor-arc/circle-method/spectral-gap bottlenecks) -> we proved we
  cannot touch those (twin primes, Zaremba-full, QUE-proof).

## HARD FILTER for a candidate problem (all must hold)
1. BOTTLENECK = search / construction / verification / pattern-finding (our strength), NOT deep analysis.
2. NOT owned/saturated: a real gap, neglected or an active collaborative frontier (Polymath-style).
3. TRACTABLE: a focused fleet (parallel reasoning + modest compute + verification) has a REALISTIC shot
   at a CONCRETE contribution in weeks: a witness, counterexample, improved bound, explicit construction,
   settled small case, or a sharp well-supported NEW conjecture.
4. VERIFIABLE: the contribution can be independently checked (so the claim is solid, not hand-wavy).
5. AVOID entirely: non-arith Hecke / Maass / QUE / arithmeticity (owned, exhausted for us).

## Domains (one survey agent each; cast WIDE, areas we would not default to)
1. Extremal / Ramsey / SAT-encodable combinatorics (construction & bound records).
2. Discrete & combinatorial geometry (chromatic number of the plane / Polymath16, packings,
   unit-distance, distinct distances, optimal configurations).
3. Computational number theory & Diophantine (specific OPEN cases settleable by structured search,
   NOT raw-FLOPS-bound; explicit witnesses/counterexamples).
4. Additive combinatorics / continued fractions / Diophantine approximation (FRESH problems where CF /
   exact-arithmetic tools fit but the area is not owned).
5. Experimental mathematics: identity / sequence / closed-form discovery (Ramanujan-machine paradigm,
   OEIS phenomena, new constants/identities) -- conjecture-generation + certification.
6. Dynamical systems / ergodic theory OUTSIDE the Hecke corner (fresh families: interval exchanges,
   billiards in fresh domains, non-classical transfer operators) where certified computation finds NEW.

## Each agent: SURVEY then adversarial-VERIFY
SURVEY (per domain): 3-5 concrete open problems matching the HARD FILTER; for each: precise statement,
current status + best recent progress (REAL refs, web-verified), why OUR edge fits, what a concrete
verifiable contribution would be, novelty/owned status, tractability (realistic shot? effort?). Rank.
VERIFY: adversarially kill the top pick -- is it really open + tractable + not owned + verifiable, or
is it secretly analysis-bound / owned / a raw-FLOPS problem / intractable?

## Rules (every agent; hooks don't fire in subagents)
READY FOR JUDGING not "done"; NEVER fabricate a citation or a status -- web-verify or mark UNVERIFIED.
Be concrete (named problems, named people, dates). Distinguish KNOWN vs CLAIMED. Write ONLY assigned
disjoint paths; no git. The point is a problem we can ACTUALLY contribute to -- ruthlessly reject
prestige problems we cannot touch.

## Synthesis (main loop)
Rank all candidates by (realistic-shot-at-concrete-contribution x not-owned x our-edge-fits x
significance). Pick THE one (or 2) worth a real attempt. Drop the rest honestly.
