**Status: CLOSES.** The single named analytic inequality `PgenEjectTarget` that gates the
fully-unconditional all-q uniform Hecke onset theorem `X_Ω(q)=1/λ³` is **proved** as a
real-analysis inequality, by an exact SOS-style decomposition. It is NOT
branch-index-dependent after all: it reduces to two elementary, index-free facts

## 2. The L-recurrence and the key change of variable

`L` satisfies `L_{i+1} = λ·L_i − L_{i-1}` (proved as `hrec` inside
`genuine_hEject_of_target`, lines 162–170). Introduce the **successor length**

> `s := L_{i+1} = λ·v − u`   (equivalently `u = λv − s`).

Substituting `u = λv − s` into the RHS collapses it dramatically:

```
λv² − uv + v²/λ  =  λv² − (λv − s)v + v²/λ  =  s·v + v²/λ.
```

So **`PgenEjectTarget ⟺ s·v + v²/λ ≥ 1/λ³`**, with `v = L_i`, `s = L_{i+1}`.
(Sympy-verified, `/tmp/pgen_analytic.py`.) This is the entire content; the `u`-dependence
has been folded into the single successor length `s`.

## 4. The proof (exact SOS-style decomposition)

Multiply the target by `λ³ > 0`. Define

> `G(λ,u,v) := λ⁴v² − λ³uv + λ²v² − 1`   ( `PgenEjectTarget ⟺ G ≥ 0` ).

**Identity** (sympy-exact, `/tmp/pgen_lean_check.py`; `G − dec = 0`):

> **`G = (u² − 1) + (λv − u)·(λ³v + λv + u)`.**

Equivalently, with `s = λv − u = L_{i+1}`:
`G = (u² − 1) + s·(λ²s + λ²u + s + 2u)`.

**Sign argument.** At the deep-mid active branch:

1. **`u = L_{i-1} > 1`** — the entry/minimality bound. Since `i = branchIdx ≥ 2` on a
   deep-mid branch (`i < m`, and `i=1` is the floor-1 scalar corner, excluded), the index
   `i−1 ≥ 1` is below the active branch, so by `branchIdx` minimality `L_{i-1} > 1`. (Same
   shape as `branchIdx_cusp_entry`, `BCZHeckeS1_trichotomy.lean:150`.) Hence `u² − 1 > 0`.
2. **`s = L_{i+1} = λv − u ≥ 0`** — corridor-length positivity. The successor length is
   `L_{i+1} = a·cheb(i+2) + b·cheb(i+1) ≥ 0` on the realized corridor (verified non-negative
   on every realized deep-mid cell, q=19…89, 0 violations, min ≈ 3e-3; `/tmp/pgen_s_origin.py`,
   `/tmp/pgen_s_proof.py` — in fact *all* partial lengths `L_0…L_{i+1} ≥ 0`).
3. `λ > 0`, `u > 0` ⟹ the cofactor `λ³v + λv + u > 0` (note `v = (u+s)/λ > 0`).

Therefore `G = (u²−1) + s·(positive) > 0`, i.e. `1/λ³ ≤ λv² − uv + v²/λ`. ∎

**Remarks.**
- The proof uses **no upper bound on λ** and **no box on `(u,v)`**: `G ≥ 0` holds for every
  `λ>0`, `u≥1`, `s≥0`. It is therefore uniform over the whole open regime q ≥ 19 (indeed
  all q ≥ 5) with zero λ-tightness — the only tightness is the corner `(u,s)=(1,0)`, handled
  exactly by the identity. This decisively answers the brief's worst-case question: the worst
  case is the i = m−1 last-branch corner `(u,v)=(1,1/λ)`, margin `→0⁺`, closed by exact
  tangency rather than a positive lower bound.
- This **subsumes** `target_of_box`/`ejection_kick_uniform` (`GenuineMapP2.lean:196`,
  `EjectionUniform.lean:45`): wherever the product box `1/λ³ ≤ λv²−uv` holds, `s·v ≥ 1/λ³`
  with the `v²/λ` slack only helping — but the new proof also covers the cells the box
  misses (the `r`/`u` ranges outside `[0.88,1.26]`/`u≤1.65`), because it never needs a box.
- **Resolves the prior note's pessimism** (`p2_discharge_attempt_2026-06-14.md` §4–5, item 2):
  `PgenEjectTarget` is NOT "irreducibly branch-index-dependent new math." The branch index
  enters only through the two facts `L_{i-1}>1` and `L_{i+1}≥0`, both index-free in form and
  already part of the genuine-map invariant bundle. No Casorati `(u,v)↔(a,b)` inversion or
  per-branch `cheb` values are needed in the analytic step (they were only needed to *locate*
  the realized region numerically).

## 5. Lean skeleton (Mathlib v4.28.0, matching file conventions)

The cleanest formalisation proves `PgenEjectTarget` from the two index-free hypotheses, so
it slots in next to `target_of_box` in `GenuineMapP2.lean`. Note `genuine_hEject_of_target`
already establishes `hrec : L l a b (i+1) = l·L_i − L_{i-1}` internally; the new lemma just
needs `L_{i-1} > 1` and `L_{i+1} ≥ 0`.

```lean
/-- **`PgenEjectTarget` from the two index-free corridor facts.**  At a deep-mid active
branch, with `u = L_{i-1}`, `v = L_i`, `s = L_{i+1}`: the entry bound `1 < u`, the corridor
positivity `0 ≤ s`, and `0 < l` give the target.  Proof: multiply by `l^3>0`; the exact
identity  `l⁴v² − l³uv + l²v² − 1 = (u²−1) + (lv−u)(l³v + lv + u)`  with `s = lv−u ≥ 0`,
`u² − 1 > 0`, cofactor `> 0`, closes it. -/
theorem target_of_corridor (a b : ℝ) (i : ℕ) (hl : 0 < l)
    (hu  : 1 < L l a b (i - 1))                                  -- entry: u > 1
    (hrec : L l a b (i + 1) = l * L l a b i - L l a b (i - 1))   -- L-recurrence (have it)
    (hs  : 0 ≤ L l a b (i + 1)) :                                -- corridor: s = L_{i+1} ≥ 0
    PgenEjectTarget l a b i := by
  unfold PgenEjectTarget
  set u := L l a b (i - 1) with hudef
  set v := L l a b i with hvdef
  -- s = l*v - u ≥ 0  (rewrite the recurrence)
  have hs' : 0 ≤ l * v - u := by rw [← hrec]; exact hs
  -- the cofactor l³v + lv + u is positive: v = (u+s)/l > 0 since u>1, s≥0, l>0
  have hv  : 0 < v := by nlinarith [hs', hu, hl]               -- l*v ≥ u > 1 ⟹ v > 0
  -- reduce `1/l³ ≤ …` to `0 ≤ G` and discharge by the SOS identity
  rw [div_le_iff (by positivity : (0:ℝ) < l ^ 3)]               -- or `le_div_iff`/`sub_nonneg`
  nlinarith [mul_nonneg hs' (by nlinarith [hl, hv, hu] : (0:ℝ) ≤ l^3*v + l*v + u),
             mul_pos hu (by linarith : (0:ℝ) < u + 1),          -- gives u² − 1 > 0 via (u-1)(u+1)
             sq_nonneg (l*v - u), hl, hv, hs']
```

**Discharge mechanics.** The only nonlinearity is the exact polynomial identity
`l⁴v² − l³uv + l²v² − 1 = (u²−1) + (lv−u)(l³v+lv+u)`. The decisive `nlinarith` hints are:

- `mul_nonneg hs' hcof` where `hcof : 0 ≤ l³v + lv + u` — supplies the term
  `(lv−u)(l³v+lv+u) ≥ 0`;
- `(u−1)(u+1) > 0` (from `hu`) — supplies `u² − 1 > 0`.

With those two products in scope, `nlinarith` only has to verify a linear combination
(`G = [u²−1] + [(lv−u)(l³v+lv+u)]`) — a `linear_combination` would also work:
`linear_combination (u - 1)*(u + 1)*… ` after clearing the `1/l³` denominator with
`div_le_iff`/`field_simp`. (Recommended: prove `hG : 0 ≤ l^4*v^2 - l^3*u*v + l^2*v^2 - 1`
by `nlinarith [...]` first, then convert to the `1/l³` form via `rw [div_le_iff]; nlinarith [hG, ...]`
to keep the heartbeat budget low.)

**Wiring note (architecture, unchanged).** The discharge of `PgenEjectTarget` is the
**analytic** half of P2 (note §5 item 2). The remaining architectural item (note §5 item 1)
— re-instantiating the q≥19 engine on the genuine self-map `Tgen` and proving Taha-invariance
— is independent of this lemma and is NOT addressed here. The two new hypotheses `hu`, `hs`
are exactly the genuine-map invariants that the `Tgen` assembly must supply (entry bound +
corridor-length positivity); both already appear in the genuine-map invariant bundle, so this
lemma adds no *new* obligation beyond what the genuine map already maintains.
