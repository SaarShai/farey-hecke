### Sorry 1: `windowMaxCos_lb` (B1a)

```lean
theorem windowMaxCos_lb (q : ℕ) (hq : 18 ≤ q) (hL : 0 < L_blk q)
    {muc : ℝ} (hmuc : muc ∈ Set.Ioo (...)) :
    2 * Real.sqrt 6 / 5 ≤ windowMaxCos (L_blk q) q hL muc
```

**Why it's hard**: The `windowMaxCos` is a `Finset.sup'` over trig expressions. The arc-coverage
argument (that L_blk is large enough that some phase φ_n lands in `[-arccos(C_D), arccos(C_D)]`)
involves:
- A floor/ceiling pigeonhole to find the right index n₀
- Bounds on |ξ_q| and |η_q| (Complex.arg corrections) for q ≥ 18
- These corrections → 0 as q → ∞ but need explicit bounds for q = 18..∞

**Key inputs available** (already proved): `arc_coverage_ineq` gives the decisive arithmetic,
but connecting it to the Finset.sup' requires a detailed argument.

**Note**: This sorry may be avoidable. See the alternative route below.

### Sorry 2: `fcorr_lb` (B1b)

```lean
theorem fcorr_lb (q : ℕ) (hq : 18 ≤ q) (hL : 0 < L_blk q)
    {muc : ℝ} (hmuc : muc ∈ Set.Ioo (...)) :
    1 / lamq q ^ 3 ≤ fcorr (L_blk q) q hL muc
```

**Why it's hard**: Two-sided trig inequality in λ, A₂, Blam, H. The intended route:
- Use `windowMaxCos ≥ C_D` (from windowMaxCos_lb)
- Bound denominator: cos²(|muc|+H) ≤ cos²(H) ≤ 24/25 (from `cos_sq_lt` + H ≥ 33π/512)
- Then: `fcorr ≥ (3λ/2 + √A₂·C_D) / (2·A₂·Blam²·(24/25))`
- Need: `25λ³(3λ/2 + √A₂·C_D) ≥ 48·A₂·Blam²`

**Numerical check at q=18**: LHS ≈ 25·6.87·5.66 ≈ 972; RHS ≈ 48·8.23·2.69 ≈ 1063. LHS < RHS!
The crude `cos²(H) ≤ 24/25` is too weak at q=18.

**Better route**: Use the exact H(q)-dependent bound:
- H(q) ≥ (⌈33q/256⌉+1)·π/(2q) ≥ (33q/256+1)·π/(2q) = 33π/512 + π/(2q)
- For q=18: H ≥ 33π/512 + π/36 ≈ 0.290 (vs 33π/512 ≈ 0.203)
- cos²(H(18)) ≤ cos²(0.290) ≈ 0.916
- With this sharper bound: numerics say fcorr(0, q=18) ≈ 0.145 = 1/λ³. Barely passes.

The exact polynomial inequality in q needs careful nlinarith witnesses. This is the
primary Aristotle task.
