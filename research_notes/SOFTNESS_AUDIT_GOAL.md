## THE HARD SOFTNESS RUBRIC (apply to every candidate; this is the whole point)
A target is SOFT (worth a fleet) only if MOST hold:
- **S1 — weak record method:** the current record was set by a one-off heuristic, an old/small search,
  or a hand-construction — NOT by exhaustive search, a proven optimum, a SAT/ILP campaign, an LLM-sweep,
  or a specialist-maintained record table.
- **S2 — wide gap:** a real, wide gap to the best upper bound (or no serious upper-bound effort) — not a
  +1 sandwiched value.
- **S3 — no TIGHT red flags:** record ≠ a clean closed-form / product / construction value; nearby sizes
  NOT proven optimal; not multiply-stability-certified; not on a cultivated table (Packomania, Brouwer/
  Grassl codes, La Jolla covering, Radziszowski Ramsey).
- **S4 — neglected:** no strong recent attack (SAT, ILP, specialist push, AlphaEvolve / FunSearch /
  CPro1 / OpenEvolve / RGCS).
- **S5 — still a NEW fact if beaten:** unowned + unbeaten NOW (web-verify), and exactly verifiable.
Verdict per target: SOFT / TIGHT / UNCERTAIN, with confidence and the evidence for each S-criterion.
If it smells like acute sets (record = construction value, exact/stable nearby, narrow gap) → TIGHT.
